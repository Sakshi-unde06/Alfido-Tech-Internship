Task 1: Static Website Hosting using AWS S3

📌 Objective
The objective of this task is to host a static website using AWS S3 and make it publicly accessible over the internet.

##Technologies Used
- Amazon Web Services (AWS)
- S3 (Simple Storage Service)
- HTML, CSS

## Steps Performed
1. Created an S3 bucket in AWS
2. Uploaded website files (index.html)
3. Enabled Static Website Hosting
4. Configured bucket permissions for public access
5. Accessed the website using the S3 endpoint URL

## 📂 Project Files
- `index.html` → Main website file  
- `Task-1 Report.pdf → Contains output and setup screenshots  

## 🌐 Live Website
🔗 http://alfido-tech.s3-website.ap-south-1.amazonaws.com

## ✅ Output
The static website was successfully hosted on AWS S3 and is accessible via a public URL.
